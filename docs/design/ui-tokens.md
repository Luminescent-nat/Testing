# 专业双主题控制台设计 token

- 版本：v1.0
- 日期：2026-11-09
- 确认日期：2026-11-12
- 状态：已确认；组件只能引用本表及已确认扩展 token
- 目标端：响应式 Web 控制台
- 暗色模式：需要
- 需求依据：R24、R25、R26

## 1. 七个核心色彩角色

下表值为十六进制颜色。`color-bg` 是正文与语义文字对比度的基准背景；页面底色和浮层底色见扩展 token。

| 类别 | 名称 | 浅色值 | 暗色值 | 用途 |
|---|---|---|---|---|
| 色彩 | color-primary | #2563EB | #60A5FA | 主按钮、链接、当前导航、焦点指示 |
| 色彩 | color-text | #0F172A | #F8FAFC | 标题、正文、主要数据 |
| 色彩 | color-text-secondary | #475569 | #CBD5E1 | 辅助说明、次要标签 |
| 色彩 | color-bg | #FFFFFF | #0F172A | 内容背景、语义文字背景 |
| 色彩 | color-success | #15803D | #4ADE80 | pass、成功提示的文字与图形 |
| 色彩 | color-warning | #A16207 | #FCD34D | 警告、待关注的文字与图形 |
| 色彩 | color-error | #B91C1C | #FCA5A5 | fail/error、破坏性操作的文字与图形 |

## 2. 扩展色彩 token

以下均为解决现有页面底色、浮层、边框、反色文字、第三级文字和禁用态所必需的显式扩展，已随 v1.0 于 2026-11-12 一并确认。后续新增或修改仍须重新确认。

| 名称 | 浅色值 | 暗色值 | 用途 |
|---|---|---|---|
| color-bg-page | #F8FAFC | #020617 | 页面整体底色 |
| color-bg-elevated | #FFFFFF | #1E293B | 卡片、对话框、菜单浮层 |
| color-text-tertiary | #64748B | #94A3B8 | 时间戳、非关键元数据；仍按正文门槛使用 |
| color-text-inverse | #FFFFFF | #0F172A | 主色实心按钮上的文字 |
| color-border | #E2E8F0 | #334155 | 非必需分隔线，不单独承担控件边界识别 |
| color-control-border | #64748B | #94A3B8 | 输入框、选择器等必需控件边界 |
| color-bg-disabled | #F1F5F9 | #1E293B | 禁用与只读控件背景 |
| color-text-disabled | #64748B | #94A3B8 | 禁用与只读文字，不与可点击主色混用 |

状态不能只靠颜色表达，必须同时提供文字或图标语义。skip 使用次级文字与明确“已跳过”标签，不新增第八个核心语义色。

## 3. 字号与行高

| 类别 | 名称 | 值 | 行高 | 用途 |
|---|---|---:|---:|---|
| 字号 | font-size-caption | 12px | 18px | 辅助标注；不用于关键正文 |
| 字号 | font-size-small | 14px | 21px | 表格次要信息、表单说明 |
| 字号 | font-size-body | 16px | 24px | 正文、输入框、主要按钮 |
| 字号 | font-size-title-sm | 20px | 30px | 卡片标题、对话框标题 |
| 字号 | font-size-title-md | 24px | 36px | 页面标题 |
| 字号 | font-size-display | 32px | 48px | 仪表盘关键数值 |

行高是字号乘 1.5 后的整数结果。不得新增 13px、15px 等表外字号。

## 4. 间距

| 类别 | 名称 | 值 | 用途 |
|---|---|---:|---|
| 间距 | space-1 | 4px | 图标与短标签的最小内部间隔 |
| 间距 | space-2 | 8px | 紧凑控件内部间距 |
| 间距 | space-3 | 12px | 表单项内部、卡片紧凑内边距 |
| 间距 | space-4 | 16px | 常规卡片内边距、表单项间距 |
| 间距 | space-6 | 24px | 卡片组与页面区块间距 |
| 间距 | space-8 | 32px | 页面主要区块间距 |
| 间距 | space-12 | 48px | 大区块分隔，不用于普通控件堆叠 |

所有 margin、padding、gap 只能引用上述值或 0；负间距和 calc 产生的表外结果同样禁止。

## 5. 圆角

| 类别 | 名称 | 值 | 用途 |
|---|---|---:|---|
| 圆角 | radius-none | 0 | 需要直角的分组边界 |
| 圆角 | radius-sm | 4px | 标签、小型按钮、输入框 |
| 圆角 | radius-md | 8px | 卡片、对话框、菜单 |
| 圆角 | radius-full | 999px | 胶囊状态标签、头像 |

## 6. 阴影

| 类别 | 名称 | 值 | 用途 |
|---|---|---|---|
| 阴影 | shadow-sm | 0 1px 2px rgba(0,0,0,0.08) | 轻量悬浮按钮 |
| 阴影 | shadow-md | 0 4px 8px rgba(0,0,0,0.12) | 下拉菜单、弹层 |
| 阴影 | shadow-lg | 0 8px 24px rgba(0,0,0,0.16) | 模态对话框、抽屉 |

两种主题共用三档阴影；不得另建发光阴影或把阴影当作焦点环。焦点使用 `4px solid color-primary`，与相邻背景对比度至少 3:1，偏移只允许 0 或 4px。

## 8. 固定断点与确认门禁

- 响应式断点固定为 `<768px`、`768～1024px`、`>1024px`；实施走查覆盖 360、767、768、1024、1025、1440px。
- token 表经用户确认后，才进入组件六段规格；九种状态、四边界态、逐组件断点和键盘行为在组件规格中定义。
- 后续确需表外取值时，先登记用途、值和双主题影响，经确认扩充本表；禁止在组件中直接写裸颜色、裸字号或非 4 倍数间距。
