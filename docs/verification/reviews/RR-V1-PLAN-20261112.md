## 0. 复现方法说明（可重复、无副作用）

pytest 对 `docs/.../evidence/` 下的文件不会自动收集 `test-platform/backend/tests/conftest.py`。为**不触碰业务 tests 目录**，评审方在自身可写目录写 `_repro_plugin.py`：用 importlib 加载 backend/tests/conftest.py 并把其 fixtures 注册为 pytest 插件；运行命令（workdir=`test-platform/backend`）：

```
PYTHONPATH=docs/verification/reviews/evidence/v1-fix-20261112 \
PYTEST_PLUGINS=_repro_plugin \
python -m pytest ../../docs/verification/reviews/evidence/v1-readiness-20261112/targeted-defect-repro.py -q -W error::pytest.PytestUnraisableExceptionWarning -rA
```

conftest 的 `isolated_storage` autouse fixture 与临时 SQLite 保证隔离；复现日志内 app.logging 仅写 backend/logs，未落真实业务 storage/库。
