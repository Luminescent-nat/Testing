## 统一定义（全平台唯一口径）

### 任务生命周期与 result

| 条件 | status | result | 展示 |
|---|---|---|---|
| 已创建/等待到期或排队 | pending | null | 等待执行 |
| 已开始执行未收尾 | running | null | 执行中 |
| 正常收尾，有任一 fail/error/timeout | completed | failed | 已完成，结果失败 |
| 正常收尾，无上述且至少一项 pass | completed | passed | 已完成，结果通过 |
| 正常收尾，选中项全 skip | completed | null | 已跳过，无通过率 |
| 平台异常无法收尾 | failed | null | 执行异常 |
| 用户取消 | cancelled | null | 已取消 |

- `status=completed` 必须满足：N>0、终态记录数 C=N、running 数 R=0。
- 测试项终态集合固定：`pass / fail / skip / error / timeout`。
- 存量空任务/零记录：保持可识别终态、result=null、显示"无执行记录"，不伪造。

### 进度口径

- `completed_items = C`（终态记录数），running 项不计入。
- `progress_percent = floor(C/N×100)`（N>0）。
- 100% 只表示全部选中项已处理，不表示全部通过。

### stop-on-failure（R31）

触发项 fail/error/timeout 后：不再启动后续项；剩余每项生成带原因 skip 记录（不执行、不消耗重试、不伪造输出）；任务 completed/failed；补记后进度 100%。skip 本身不触发停止。

### 通过率（R11/R12）

- 测试项：`pass_rate = pass / (pass + fail + error + timeout)`，skip 不进分子分母，分母 0 返回 null（不显示 0% 或 100%）。
- Dashboard 任务通过率：`passed任务 / (passed任务 + failed任务)`，仅统计 completed 且有有效业务结果的任务；全 skip/零记录/running/failed/cancelled 不进分母，分母 0 为 null。

## 风险登记

| 编号 | 风险 | 概率/影响 | 应对 |
|---|---|---|---|

| RSK-04 | 静态 27 项覆盖被误写成实机 27 项通过 | 高/虚假验收 | 静态矩阵、实机矩阵、跳过原因分列，禁止合并为"UPFM 已完成"。 |
| RSK-05 | token 未确认即开发或对比度目测 | 中/UI 返工 | token 确认为 UI 前置门禁，走查保存测量值、边界截图、键盘结果。 |
| RSK-06 | 清理时把 archive/报告/备份当可重建缓存 | 中/数据不可恢复 | 逐项分类验证唯一性与恢复依据，受保护数据存在性及哈希复核。 |
