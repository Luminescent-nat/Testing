# ADR-002：设备授权以服务端归属为准

- 状态：accepted
- 日期：2026-11-09

## 背景

R5～R7 要求列表、详情、手动/AI 创建、报告和 WS 使用一致授权；R6 禁止普通用户通过刷新认领设备。当前按 PC 判断或各入口分散校验会产生越权路径。

## 决策

建立唯一服务端设备授权策略，`owner_id` 决定操作权限，`pc_identifier` 只作普通用户的分组约束。

- 管理员可操作全平台设备，普通用户仅可操作本人 owner 且 PC 一致的设备。
- 新发现设备保持 `owner_id=NULL`，只有管理员可分配或改派。
- 手动、AI、WS、报告复用用户状态与资源归属校验。
- 存量未分配设备先出清单，由管理员确认归属。

## 备选方案

- 方案 A：重写为独立权限服务 — 否决；超出本轮范围，增加运维与迁移风险。
- 方案 B：在现有入口分别补 PC 判断 — 否决；仍会产生口径漂移和漏检。
- 方案 C：现有服务端增加共享授权策略 — 采纳；改动边界清晰且能覆盖所有入口。

## 后果

正面影响：消除刷新认领和跨入口越权。负面影响：存量 owner 为空的设备在分配前不可被普通用户操作。跟进项：补未分配设备迁移清单、统一 403/1008 测试和并发改派验证。
