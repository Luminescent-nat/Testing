# ADR-008：双主题 UI 采用 token 先行

- 状态：accepted
- 日期：2026-11-09

## 背景

R24～R26 要求双主题 token 先确认、组件九状态与四边界态完整、固定断点和实测可访问性。现有主题变量提供基础，但阴影、语义色和页面状态未全部受同一规范约束。

## 决策

在现有 Vue 3/Element Plus 主题上演进，以确认后的双主题 token 为唯一样式来源。

- 固定七色角色、六档字号、4px 间距、四档圆角和三档阴影。
- token 确认后才编写组件六段规格，不直接重写页面。
- 每组件定义九种状态、四边界态、三档断点和键盘行为。
- 对比度、对齐、间距、截图和 Tab 顺序必须实际走查。

## 备选方案

- 方案 A：更换 UI 框架并重写前端 — 否决；实现成本与回归风险高，非美观改进的必要条件。
- 方案 B：直接逐页调整裸样式 — 否决；主题和状态会继续漂移。
- 方案 C：保留框架、先 token 后组件小步整改 — 采纳；复用现有主题且可逐页验收。

## 后果

正面影响：亮暗主题和组件行为一致。负面影响：既有裸样式需逐步迁移，短期有文档和走查成本。跟进项：token 当前仍为草案，用户确认前不得开始组件实现。

accepted；2026-11-12 用户确认。
